# ex01 — exercise template

This README contains a template you should fill when you start working on ex01. It will help you document the goal, design, and usage of your solution.

Sections to complete when you implement the exercise:

- **Goal:** Short description of the problem the exercise asks you to solve.
- **Files:** List the source files you created and their responsibilities.
- **How it works:** Brief explanation of the approach and algorithm.
- **Key methods/classes:** For each class or public method, write a one-line purpose and explain inputs/outputs.
- **How to compile:** Example command(s) to compile the code in this folder.
- **How to run:** Example command(s) to run the program, including example input and expected output.
- **Edge cases & tests:** Note important test cases (empty input, negative values, large values) and how your program handles them.
- **Common errors:** Things to watch out for (package mismatches, wrong `main` class name, off-by-one errors).

Use this template to keep each exercise well-documented and reproducible.
